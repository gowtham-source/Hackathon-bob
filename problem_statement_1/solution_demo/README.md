# Multi-Agent Competitive Analysis Pipeline

A sophisticated research pipeline using the Gemini Python SDK (`google-genai`) that automatically analyzes competitors for any product.

## Overview

This pipeline implements three specialized AI agents that work sequentially to produce comprehensive competitive analysis reports:

1. **Scout Agent** - Identifies and summarizes competitors in the product space
2. **Analyst Agent** - Performs deep-dive comparison of top 3 competitors across pricing, features, and target audience
3. **Reporter Agent** - Compiles all findings into a professional markdown brief

## Architecture

- **No frameworks or wrappers** - Uses `google-genai` SDK directly
- **Independent API calls** - Each agent makes its own Gemini API call
- **Context forwarding** - Agents pass their outputs as context to the next agent
- **Model**: `gemini-3.1-flash-lite` for all agents

## Setup

1. Ensure you have the required dependencies installed:
```bash
pip install google-genai python-dotenv
```

2. Set up your API key in `.env` file:
```
GEMINI_API_KEY=your_api_key_here
```

## Usage

### Run the pipeline with default example (Notion):
```bash
python problem_statement_1/solution_demo/competitive_analysis_pipeline.py
```

### Use in your own code:
```python
from competitive_analysis_pipeline import run_competitive_analysis_pipeline, save_report

# Analyze any product
product_name = "Slack"
report = run_competitive_analysis_pipeline(product_name)

# Save the report
save_report(product_name, report)
```

## Pipeline Flow

```
User Input (Product Name)
    ↓
Scout Agent (Gemini API Call #1)
    ↓ [Competitor List]
Analyst Agent (Gemini API Call #2)
    ↓ [Detailed Comparison]
Reporter Agent (Gemini API Call #3)
    ↓
Markdown Report (Saved to file)
```

## Output

The pipeline generates a comprehensive markdown report with:
- Executive Summary
- Market Overview
- Competitive Landscape
- Top 3 Competitors Deep Dive (with comparison table)

## Technical Details

### SDK Pattern
Uses the modern `genai.Client()` instantiation pattern:
```python
from google import genai

client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))
response = client.models.generate_content(
    model="gemini-3.1-flash-lite",
    contents=prompt
)
```

### Agent Independence
Each agent is a separate function that:
- Takes specific inputs (product name + context from previous agents)
- Makes an independent Gemini API call
- Returns structured output for the next agent

### Error Handling
The pipeline includes comprehensive error handling with detailed error messages and stack traces for debugging.

## Customization

You can easily customize:
- **Model**: Change `MODEL_NAME` constant to use different Gemini models
- **Prompts**: Modify agent prompts to adjust analysis focus
- **Output format**: Customize the Reporter Agent's prompt for different report structures
- **Number of competitors**: Adjust the Scout Agent to find more/fewer competitors
