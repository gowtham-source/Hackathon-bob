## Abstract skeleton (5 bullets)
- **Problem**: Vision-language models like CLIP demonstrate strong zero-shot capabilities but adapting them to downstream tasks with prompt learning methods introduces substantial trainable parameters that limit deployment in resource-constrained scenarios.
- **Limitation of prior work**: Existing multi-modal prompt learning methods (e.g., MaPLe, MMRL) use independent projection layers per transformer layer, resulting in parameter redundancy without explicit gradient sharing across modalities and layers.
- **Our approach**: We propose MMRL++, which introduces Shared-Residual Representation Aligner (SRRA) using shared base weights with layer-specific low-rank residuals, and Progressive Representation Composition (PRC) for inter-layer semantic flow, achieving parameter efficiency while maintaining multi-modal alignment.

- **Implication**: Our shared-residual design enables efficient vision-language adaptation suitable for edge deployment and resource-constrained applications, while the progressive composition mechanism enhances intra-modal interaction beyond single-layer token injection.

| ID | Sub-topic | Summary | Equation | Source symbol | Motivating cites |
|----|-----------|---------|----------|---------------|------------------|
| M1 | Learnable Representation Tokens | 5 learnable tokens (512-dim) shared across modalities, injected into transformer layers 6-12 | $\mathbf{R} \in \mathbb{R}^{n_r \times d_r}$ where $n_r=5, d_r=512$ | `MultiModalRepresentationLearner_pp.compound_rep_tokens` | [@guo2025mmrl], [@khattak2023maple] |
| M2 | Shared-Residual Representation Aligner (SRRA) | Shared base linear layer + layer-specific rank-4 residual adaptations: $\mathbf{W}_l = \mathbf{W}_{base} + \mathbf{A}_l \mathbf{B}_l$ | $f_l(\mathbf{x}) = (\mathbf{W}_{base} + \mathbf{A}_l \mathbf{B}_l)\mathbf{x} + \mathbf{b}_l$ | `Shared_Residual_Representation_Aligner` | [@hu2021lora], [@huan2025fine] |
| M3 | Residual Aligner Module | Low-rank decomposition with rank $r=4$: learns $\mathbf{A} \in \mathbb{R}^{d_{out} \times r}$ and $\mathbf{B} \in \mathbb{R}^{r \times d_{in}}$ | $\Delta \mathbf{W} = \mathbf{A} \mathbf{B}$ | `Residual_Aligner` | [@hu2021lora] |
| M4 | Progressive Representation Composition (PRC) | Inter-layer composition with beta-weighted mixing: $\mathbf{R}_l = \beta \mathbf{R}_{l-1} + (1-\beta) \mathbf{R}_{base}$ | $\mathbf{R}_l^{(t+1)} = \beta \mathbf{R}_l^{(t)} + (1-\beta) \mathbf{R}_0$ | `MultiModalRepresentationLearner_pp.forward` (implicit in layer iteration) | [@guo2025mmrl] (extends) |
| M5 | Multi-Modal Alignment Loss | Weighted cross-entropy on original + enhanced logits + cosine similarity regularization | $\mathcal{L} = \alpha \mathcal{L}_{CE}(\mathbf{z}, y) + (1-\alpha) \mathcal{L}_{CE}(\mathbf{z}_{rep}, y) + \lambda (\mathcal{L}_{cos}^{img} + \mathcal{L}_{cos}^{text})$ | `MMRLpp_Loss` | [@guo2025mmrl], [@khattak2023maple] |
| M6 | Text Encoder Integration | Inject representation tokens into text transformer, extract features from EOT token position | $\mathbf{t} = \text{TextEnc}(\mathbf{e}_{text}, \mathbf{R}_{text})$ | `TextEncoder_MMRLpp` | [@radford2021clip], [@khattak2023maple] |
| M7 | Visual Encoder Integration | Inject representation tokens into vision transformer, dual-path feature extraction | $\mathbf{v}, \mathbf{v}_{rep} = \text{VisEnc}(\mathbf{x}, \mathbf{R}_{vis})$ | `clip.model_mmrlpp.VisionTransformer` | [@radford2021clip], [@dosovitskiy2020vit] |
